# Code of Conduct

We want this project to feel rigorous, respectful, and welcoming to contributors, users, and maintainers.

## Expected behavior

- Be respectful, constructive, and specific in technical discussions.
- Assume good intent while still holding a high bar for quality.
- Focus review feedback on code, design, documentation, and operations, not on people.
- Share context, tradeoffs, and evidence when challenging an idea.
- Help keep the project safe for contributors with different backgrounds and experience levels.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks
- Discriminatory language or exclusionary behavior
- Bad-faith trolling, repeated derailing, or inflammatory conduct
- Publishing private information without permission
- Sexualized language or imagery in project spaces

## Scope

This code of conduct applies in repository issues, pull requests, discussions, reviews, and other project-managed collaboration spaces.

## Enforcement

Project maintainers may edit, remove, or reject contributions and interactions that violate this code of conduct.

If you experience or witness unacceptable behavior, contact the maintainers through a private GitHub channel when possible instead of escalating publicly.
