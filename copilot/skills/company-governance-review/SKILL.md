# Company governance review

Use this skill when a user asks whether a company is operating with the right approvals and policy guardrails.

## Workflow

1. Read the company details.
2. Read the board summary.
3. Read the company policies.
4. Summarize approval rules, data-sharing posture, and any governance flags.

## Output

Return a concise governance assessment with clear board-facing risks and follow-up actions.
